## 👁️ What is belong.ai?

In the AI era, people increasingly express emotions to machines
because they feel unheard by humans.

**belong.ai** is built on one belief:

> *AI should not replace human emotional connection.*
> *It should help humans find humans who genuinely understand them.*

This is not therapy.
This is not dating.
This is not a chatbot.

This is an emotionally intelligent anonymous ecosystem
where humans find where they truly belong.
